秘密鍵（secret.key）

Python 版（attendance_code.py）と同じ secret.key をそのまま使えます。鍵はこのページの中だけで使われ，どこにも送信されません。
「新しい鍵を作成」は最初の1回だけ。作った鍵は必ずバックアップし，学生に渡さないこと（なくすと配布済みカードがデコードできなくなります）。
「記憶する」をオンにすると，次回からは読み込み不要になります（自分専用の PC でのみ使ってください）。

Googleフォームの事前入力URL

フォーム編集画面の「⋮」→「事前入力したURLを取得」で，コード欄に仮の値（XXXX など）を入れて取得したURLから，末尾の仮の値を消したものです。このブラウザに保存されます。

授業IDの対応表（courses.csv）

ID授業名

Python 版の courses.csv と同じ形式です。ここでの変更はこのブラウザに保存されます。Python 版でも使うときは「保存」で書き出してください。カードを配ったあとに ID と授業名の対応を変えないでください。

カードを作る

回数を2以上にすると，初回から「間隔」日ごとの授業日の分をまとめて作ります（各回の番号は開始番号から振り直し）。日付なしカードを追加で刷るときは，開始番号を続きにしてください。

Python 版で作ったカードCSVを印刷する

印刷

印刷ダイアログでは 用紙 A4・余白「なし」・倍率 100%（「用紙に合わせる」をオフ） にしてください。ずれると切断ガイド線とカードの位置が合いません。
カードCSVの保存は記録用です（デコードには不要。Python 版の typst でも印刷できます）。

フォーム回答CSVのデコード

結果は元の列の右に「日付・カードNo・授業ID・授業名・判定」を足したもので，Python 版の decode と同じです。保存するCSVは Excel でそのまま開けます（BOM付き UTF-8）。
