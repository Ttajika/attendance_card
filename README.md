# 出席カード

QRコード付きの出席カードを印刷し，Googleフォームの回答から「どの日の・何番のカードか」を復元するためのツール一式です．

カードのQRコードには，授業日・カード番号・授業IDを暗号化したコード（例：`FC515-K7NN-D46S-CXM2-2NMC`）がフォームURLに埋め込まれています．秘密鍵 `secret.key` がないとコードの中身は読めず，偽造もできません．

## どちらを使うか（ブラウザ版／Python＋Typst 版）

同じことができる版が2つあります．**迷ったらブラウザ版**を使ってください．2つは完全に互換なので，途中で乗り換えたり併用したりしても問題ありません（同じ `secret.key`・`courses.csv` を使え，どちらで作ったカードもどちらでデコードできます）．

| | ブラウザ版（`web/`） | Python＋Typst 版 |
|---|---|---|
| 準備 | 不要（`web/index.html` を開くだけ） | Python・Typst・フォントのインストールが必要 |
| 操作 | 画面のボタンで操作 | コマンドを打って操作 |
| 印刷 | ブラウザから直接印刷．用紙・余白・倍率の設定に注意 | PDF ができるので，ずれずに印刷でき，保存・共有もしやすい |
| 刷り直し | 「カードCSVを保存」しておく必要がある | CSV が必ず残るので，いつでも同じカードを刷り直せる |
| カスタマイズ | 授業名・カード名など画面で変えられる範囲のみ | `.typ` を編集してレイアウトを自由に変えられる |
| 自動化 | できない | スクリプトやシェルから一括処理できる |

- **ブラウザ版が向いている人：** コマンド操作に慣れていない，ソフトを入れたくない，とりあえず試したい．
- **Python＋Typst 版が向いている人：** カードの見た目を細かく調整したい，PDF で残したい，毎学期の作業をコマンドでまとめて済ませたい．

ブラウザ版の使い方は「[ブラウザ版の使い方](#ブラウザ版の使い方web)」を，Python＋Typst 版の使い方は「[Python＋Typst 版の使い方](#pythontypst-版の使い方)」を見てください．

## ファイル構成

| ファイル | 内容 |
|---|---|
| `attendance_code.py` | コードの生成・デコードを行う Python スクリプト（標準ライブラリのみで動作） |
| `attendance_card.typ` | 出席カード（授業日つき）の Typst テンプレート |
| `nodate_card.typ` | 日付なしカード（発言カードなど）の Typst テンプレート |
| `card_layout.typ` | 上の2つが共通で使うレイアウト（カード寸法・切断ガイド線・QRコード配置） |
| `secret.key` | 秘密鍵（`keygen` で作成．**学生に配布しないこと**） |
| `web/` | ブラウザ版（HTML＋JavaScript）．下の「ブラウザ版の使い方」を参照 |
| `courses.csv` | 授業IDと授業名の対応表（`course add` で作成．任意） |
| `cards_YYYYMMDD.csv` | `generate` で作るカード用データ（Typst が読み込む） |
| `cards_nodate_開始-終了.csv` | `generate --no-date` で作る日付なしカード用データ |

## Python＋Typst 版の使い方

### 必要なもの

- Python 3.8 以上
- Typst（パッケージ `@preview/tiaoma:0.3.0` を使用）
- フォント「Harano Aji Gothic」

### 0. Googleフォームの準備（最初の1回だけ）

QRコードを読むと，コード欄が最初から埋まった状態でフォームが開くようにします．そのために「事前入力したURL」を取得して，スクリプトに設定します．

1. フォームに，コードを入れる質問を「記述式」で作ります（例：「出席コード」）．学籍番号・氏名など，ほかの質問は自由です．
2. フォームの編集画面の右上にある「⋮」（その他）から「**事前入力したURLを取得**」を選びます．
3. 回答画面と同じ形のページが開くので，コードの欄に目印になる値（例：`XXXX`）を入れ，下の「**リンクを取得**」→「**リンクをコピー**」を押します．
4. コピーしたURLは次のような形をしています．

   ```
   https://docs.google.com/forms/d/e/1FAIpQ.../viewform?usp=pp_url&entry.1091180216=XXXX
   ```

   末尾の `XXXX` を消し，`=` で終わる形にして，`attendance_code.py` の `FORM_URL` に貼ります．

   ```python
   FORM_URL = ("https://docs.google.com/forms/d/e/"
               "1FAIpQ.../"
               "viewform?usp=pp_url&entry.1091180216=")
   ```

   スクリプトは，この末尾に各カードのコードをつなげてQRコードのURLにします．`FORM_URL` は最初は空欄で，空欄のまま `generate` を実行するとエラーになります．

**注意**
- `entry.数字` の部分は質問ごとに決まった番号です．フォームの文言を直しても変わりませんが，**コードの質問を削除して作り直すと番号が変わります**．その場合は上の手順でURLを取り直し，カードのCSVも作り直してください．
- ほかの質問も事前に埋めたいときは，3 でその欄にも値を入れれば，`&entry.別の数字=値` がURLに付きます．
- 学生が手でコードを打ち直すこともできます．フォームの説明に「QRコードが読めない場合は，カードに書かれたコードを入力してください」と書いておくとよいです．
- 回答は，フォームの「回答」タブ →「⋮」→「回答をダウンロード（.csv）」でCSVにできます（4 で使います）．
- メニューの名前は，Google側の変更で多少変わることがあります．

### 1. 鍵の作成（最初の1回だけ）

```
python attendance_code.py keygen
```

`secret.key` ができます．**必ずバックアップしてください．** 鍵をなくすと，配布済みのカードがデコードできなくなります．既に鍵がある場合は上書きしません．

### 1'. 授業IDの登録（任意）

授業IDに名前を付けておくと，カードに授業名が印刷され，デコード結果にも授業名の列が入ります．

```
python attendance_code.py course add "ミクロ経済学 出席" --id 3
python attendance_code.py course add "ミクロ経済学 発言"
python attendance_code.py course list
```

- 対応表は `courses.csv`（`id,name` の2列）に保存されます．Excel などで直接編集しても構いません．
- `--id` を省略すると，登録済みの最大の番号の次が使われます．IDは 0〜255 です．
- 登録した授業名は，`generate --course "ミクロ経済学 出席"` のように番号の代わりに指定できます．
- **一度カードを配ったIDの授業名を変えても，デコード結果の授業名は新しい名前になります．** IDの使い回しはしないでください．
- `courses.csv` も `.gitignore` の `*.csv` に該当するため，GitHub には上がりません．別の PC で使うときは，`secret.key` と一緒にコピーしてください．

### 2. カード用CSVの生成（授業日ごと）

```
python attendance_code.py generate --date 2026-11-04 --count 100 --start 1 --course 1
```

`--date` を省略すると今日の日付になります．

毎週の授業の分をまとめて作るときは `--repeat` を使います．次の例では，2026-10-07 から毎週1回，15回分のCSVを作ります．

```
python attendance_code.py generate --date 2026-10-07 --repeat 15
```

`cards_20261007.csv`，`cards_20261014.csv`，… と授業日ごとにファイルができます．`--merge` を付けると，`cards_20261007-20270113.csv` のように1つのファイルにまとまります．各回のカード番号は，それぞれ `--start` から振り直します．

| オプション | 意味 | 既定値 |
|---|---|---|
| `--date` | 授業日（YYYY-MM-DD）．`--repeat` を使うときは初回の日付 | 今日 |
| `--count` | 1回あたりの枚数 | 100 |
| `--start` | 開始番号 | 1 |
| `--course` | 授業ID（0〜255），または `courses.csv` に登録した授業名 | 0 |
| `--repeat` | 何回分作るか | 1 |
| `--interval` | 回と回の間隔（日数） | 7（毎週） |
| `--merge` | 複数回分を1つのCSVにまとめる | なし |
| `--out` | 出力ファイル名（1ファイルに出すときのみ） | `cards_YYYYMMDD.csv` |

#### 日付なしカード（発言カードなど）

授業日に関係なく使うカード（発言したときに渡す「発言カード」など）は，`--no-date` で作ります．

```
python attendance_code.py generate --no-date --count 100 --start 1 --course 2
```

`cards_nodate_1-100.csv` ができます．

- 日付が入っていないので，いつ使っても有効です．いつ使われたかは，フォームの回答のタイムスタンプで分かります．
- 同じカードの2回目以降の回答は `重複` になるので，1枚1回限りという扱いは出席カードと同じです．
- 出席カードと区別できるよう，**`--course` に出席カードとは別の値**を付けておくことをおすすめします．同じ授業IDでも，日付の有無で別のカードとして扱われます．
- 追加で刷るときは，`--start 101` のように番号を続けてください．同じ番号で作り直すと，デコード結果では同じカードとみなされます．
- `--date`／`--repeat`／`--merge` とは一緒に使えません．

### 3. カードの印刷

読み込む CSV を `--input csv=...` で指定して PDF を作ります．

```
typst compile attendance_card.typ cards_20261111.pdf --input csv=cards_20261111.csv
```

`--input` を省略すると，`attendance_card.typ` の中の既定のファイル名（`cards_20261104.csv`）を読みます．`--merge` で作ったCSVを指定すれば，全回分のカードを1つのPDFにまとめて印刷できます．

A4 1枚に2列×5段でカードが並び，切断用のガイド線が入ります．QRコードの右には，`courses.csv` に登録した授業名が印刷されます．登録がないときは，`.typ` ファイルの `course_name` の値が印刷されます．

日付なしカードは `nodate_card.typ` で印刷します．

```
typst compile nodate_card.typ --input csv=cards_nodate_1-100.csv
```

カードの名前（既定は「発言カード」）は，`nodate_card.typ` の `card_name` で変えられます．カードの寸法やガイド線を変えるときは `card_layout.typ` を編集すると，両方のカードに反映されます．

### 4. 回答のデコード

Googleフォームの回答を CSV でダウンロードし，次を実行します．

```
python attendance_code.py decode フォーム回答.csv
```

`フォーム回答_decoded.csv` が作られ，元の列の右に次の列が足されます．

| 列 | 内容 |
|---|---|
| 日付 | カードの授業日（日付なしカードは `なし`） |
| カードNo | カード番号 |
| 授業ID | `--course` で指定した値 |
| 授業名 | `courses.csv` に登録した授業名（未登録なら空欄） |
| 判定 | `OK`／`不正コード`／`重複（n行目と同じカード）` |

- コードが入った列は自動で見つけます．うまくいかないときは `--column 列名` で指定してください．
- セルに URL が丸ごと入っていても，コードの部分だけを取り出して読みます．
- 出力は BOM 付き UTF-8 なので，Excel でそのまま開けます．

### 単発の確認

```
python attendance_code.py check FC515-K7NN-D46S-CXM2-2NMC
```

## ブラウザ版の使い方（web/）

Python や Typst を使わずに，ブラウザだけで使える版です．この節だけ読めば使い始められます．

### 準備するもの

- `web/` フォルダ（中の4ファイル `index.html`・`app.js`・`core.js`・`qrcode.js` をまとめて置いておけば，どこに移しても動きます）
- Chrome・Edge・Safari・Firefox などのブラウザ
- Googleフォーム（このあと作ります）

インストールは不要です．`web/index.html` をダブルクリックしてブラウザで開いてください．インターネット接続も要りません．画面上部に「準備」「カード作成・印刷」「回答のデコード」「単発の確認」の4つのタブがあります．

### 1. Googleフォームを作る（最初の1回だけ）

QRコードを読むと，コード欄が最初から埋まった状態でフォームが開くようにします．

1. Googleフォームを新しく作り，コードを入れる質問を「記述式」で作ります（例：「出席コード」）．学籍番号・氏名など，ほかの質問は自由です．フォームの説明に「QRコードが読めない場合は，カードに書かれたコードを入力してください」と書いておくとよいです．
2. フォームの編集画面の右上にある「⋮」（その他）から「**事前入力したURLを取得**」を選びます．
3. 回答画面と同じ形のページが開くので，コードの欄に目印の値（例：`XXXX`）を入れ，下の「**リンクを取得**」→「**リンクをコピー**」を押します．
4. コピーしたURLは次のような形です．末尾の `XXXX` を消して，`=` で終わる形にしておきます．

   ```
   https://docs.google.com/forms/d/e/1FAIpQ.../viewform?usp=pp_url&entry.1091180216=XXXX
   ↓
   https://docs.google.com/forms/d/e/1FAIpQ.../viewform?usp=pp_url&entry.1091180216=
   ```

`entry.数字` は質問ごとに決まった番号です．質問の文言を直しても変わりませんが，**コードの質問を削除して作り直すと番号が変わり，配ったカードのQRコードが使えなくなります．** その場合はURLを取り直して，カードを作り直してください．

### 2. 「準備」タブで初期設定する（最初の1回だけ）

ブラウザ版は設定をファイルに保存しておき，**ページを開くたびに読み込んで使う**のが基本です．ブラウザにも設定を覚えさせられますが，閲覧データやキャッシュを消したとき，ブラウザを変えたとき，PC を買い替えたときに消えてしまいます．そこで，次の3つをまとめて保管するフォルダ（例：`出席カード設定`）を1つ作っておいてください．

| 保管するもの | 中身 |
|---|---|
| `secret.key` | 秘密鍵（(1) で作成） |
| `form_url.txt` など | フォームの事前入力URLを貼ったメモ（(2) で作成） |
| `courses.csv` | 授業の登録内容（(3) で作成．授業を登録する場合のみ） |

このフォルダは**別の場所（USBメモリやクラウドなど）にもバックアップし，学生には渡さないでください．**

**(1) 秘密鍵を作る**

「**新しい鍵を作成して保存**」を押すと，`secret.key` がダウンロードされます．上のフォルダに移してください．

- この鍵がないとカードを作ることも，回答をデコードすることもできません．**なくすと配布済みのカードが読めなくなります．**
- **学生には絶対に渡さないでください．** 鍵があればカードを偽造できます．
- 新しい鍵を作り直すと，前の鍵で作ったカードは新しい鍵ではデコードできません．鍵の作成は最初の1回だけです．

画面右上の表示が「秘密鍵：読み込み済み」になれば準備完了です．

**(2) フォームのURLを貼る**

「Googleフォームの事前入力URL」の欄に，1 の 4 で作った `=` で終わるURLを貼ります．この欄が空のままだと，カードは作れません．同じURLをテキストファイル（例：`form_url.txt`）にも貼って，上のフォルダに保存しておきます．

**(3) 授業を登録する（任意）**

授業名を登録しておくと，カードに授業名が印刷され，デコード結果にも授業名が出ます．「授業名」に名前を入れて「**登録**」を押してください．授業ID（0〜255）は空欄なら自動で振られます．登録が終わったら「**courses.csv として保存**」を押し，上のフォルダに保存します．授業を追加・削除したときも，そのつど保存し直してください．

- 出席カードと発言カードのように，**カードの種類ごとに別の授業を登録**しておくと区別しやすくなります（例：「ミクロ経済学 出席」「ミクロ経済学 発言」）．
- **カードを配ったあとは，IDと授業名の対応を変えないでください．** デコード結果の授業名は，その時点の対応表で決まります．

### 2'. ページを開くたびにすること

`web/index.html` を開いたら，作業の前に「準備」タブで次の3つを行います．

1. 「**既存の鍵を読み込む**」で `secret.key` を選ぶ（右上が「秘密鍵：読み込み済み」になります）．
2. 授業を登録している場合は，「**courses.csv を読み込む**」で `courses.csv` を選ぶ（下の表に授業が並びます）．
3. 「Googleフォームの事前入力URL」が自分のフォームのURLになっているか確認する．空欄や違うURLになっていたら，`form_url.txt` から貼り直す（空欄のままだと「作成」を押してもエラーになります）．

**3 の確認は特に大事です．** URLが違ったまま印刷すると，QRコードが自分のフォームにつながらないカードになります．

「**このブラウザに記憶する**」にチェックを入れると，鍵の読み込みを省略できます．ただし鍵がブラウザの中に保存されるので，自分専用の PC でのみ使い，その場合でも上のフォルダの `secret.key` は消さずに残しておいてください（「記憶を消す」で取り消せます）．

### 3. 「カード作成・印刷」タブでカードを作って印刷する

**(1) 出席カード（授業日つき）**

「出席カード（授業日つき）」を選び，次の欄を埋めて「**作成**」を押します．

| 欄 | 意味 |
|---|---|
| 授業日（初回） | カードに入る授業日．回数が2以上なら初回の日付 |
| 回数 | 何回分まとめて作るか（例：毎週の授業15回分なら 15） |
| 間隔（日） | 回と回の間隔（毎週なら 7） |
| 1回あたりの枚数 | 履修者数より少し多めに |
| 開始番号 | カード番号の始まり（各回とも，この番号から振り直します） |
| 授業 | 2-(3) で登録した授業．未登録なら「番号を直接指定」で授業IDを入れます |
| カードの名前・注意書き | カードに印刷される文字．自由に変えられます |

**(2) 日付なしカード（発言カードなど）**

授業日に関係なく使うカード（発言したときに渡す「発言カード」など）は，「日付なしカード」を選んで作ります．

- いつ使っても有効です．いつ使われたかは，フォームの回答のタイムスタンプで分かります．
- 出席カードと同じく，1枚1回限りです（2回目以降の回答は `重複` と判定されます）．
- 出席カードとは**別の授業**を選んでおくと区別しやすくなります．
- 追加で刷るときは，開始番号を前回の続き（例：前回 1〜100 なら 101）にしてください．同じ番号で作ると，デコード結果では同じカードとみなされます．

**(3) 印刷する**

作成すると，下にプレビューが表示されます（A4 1枚に2列×5段）．「**印刷する**」を押し，印刷ダイアログで次のように設定してください．

- 用紙：**A4**
- 余白：**なし**
- 倍率：**100%**（「用紙に合わせる」などはオフ）

設定がずれると，切断用のガイド線とカードの位置が合いません．印刷したらガイド線に沿って切り離します．

**(4) カードCSVを保存しておく（推奨）**

「作成」を押すたびにコードは新しく作られるので，**同じカードを後から刷り直すには，作ったときのデータが必要です．** 「**カードCSVを保存**」で `cards_20261104.csv` のようなファイルを保存しておき，刷り直すときは「**Python 版で作ったカードCSVを印刷する**」の欄から読み込んでください（名前は Python 版ですが，ブラウザ版で保存したCSVも読めます）．読み込むとカードの名前・注意書きは既定の文に戻るので，変えていた場合は入れ直してください．なお，このCSVがなくても回答のデコードはできます．

### 4. 授業でカードを配る

学生はカードのQRコードをスマートフォンで読み，開いたフォームに学籍番号などを入れて送信します．コード欄は最初から埋まっています．QRコードが読めない学生は，カードに印刷されたコードを手で入力できます（大文字・小文字や `O`/`0`，`I`/`L`/`1` の違いは自動で吸収されます）．

### 5. 「回答のデコード」タブで回答を確認する

1. Googleフォームの「回答」タブ →「⋮」→「**回答をダウンロード（.csv）**」でCSVを保存します（zip で落ちてきたら展開してください）．
2. 「Googleフォームの回答CSV」でそのファイルを選び，「**デコード**」を押します．コードの列は自動で見つけます．うまくいかないときは「コードの列」で選んでください．
3. 結果が表に表示されます．「**結果をCSVで保存**」を押すと `（元のファイル名）_decoded.csv` が保存され，Excel でそのまま開けます．

元の列の右に，次の列が足されます．

| 列 | 内容 |
|---|---|
| 日付 | カードの授業日（日付なしカードは `なし`） |
| カードNo | カード番号 |
| 授業ID | カードを作るときに選んだ授業のID |
| 授業名 | 登録した授業名（未登録なら空欄） |
| 判定 | `OK`／`不正コード`／`重複（n行目と同じカード）` |

結果の見方：

- **`OK` でも，日付が回答日（タイムスタンプ）と違う**場合は，別の日のカードを使い回した可能性があります．
- **`重複`**：同じカードで2回以上回答があると，2件目以降がこうなります．
- **`不正コード`**：コードの打ち間違い，またはでたらめなコードです（偶然通る確率は約43億分の1）．

### 6. 「単発の確認」タブ

コード1つ（QRコードのURLでも可）を貼って「**確認**」を押すと，そのカードの日付・番号・授業が表示されます．学生から問い合わせがあったときなどに使います．

### 補足

- **Python＋Typst 版と完全に互換です．** 同じ `secret.key`・`courses.csv` を使え，どちらで作ったカードもどちらでデコードできます．
- 秘密鍵はページの中だけで使われ，外部には送信されません．QRコードの生成ライブラリ（[qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator)，MIT ライセンス）も `web/qrcode.js` として同梱しているので，外部からスクリプトを読み込むこともありません．
- フォームURLと授業の登録内容は，入力するとブラウザ（localStorage）にも保存され，次に開いたときに表示されます．ただし閲覧データを消すと消えるので，あくまで補助と考え，2' のとおりファイルから読み込む・確認する運用にしてください．
- カード番号は 65535 番まで使えます．

| ファイル | 内容 |
|---|---|
| `web/index.html` | 画面と印刷レイアウト |
| `web/app.js` | 画面の処理 |

## 運用上の注意

- **出席日の確認：** 判定が `OK` でも，日付が回答日（タイムスタンプ）と違う場合は，別の日のカードを使い回した可能性があります．
- **重複：** 同じカードで2回以上回答があると，2件目以降が `重複` になります．
- **手入力の揺れ：** 学生がコードを手入力するときの大文字・小文字，`O`/`0`，`I`/`L`/`1` の違いは自動で吸収します．
- **番号の上限：** 65535番まで．日付は 2020-01-01 から約179年分扱えます．

## コードの仕組み

13バイトのデータを Crockford Base32（`I` `L` `O` `U` を使わない32文字）で21文字にしています．

```
nonce(4B, 乱数) | 暗号文(5B) = [日付(2B) | 番号(2B) | 授業ID(1B)] XOR 鍵ストリーム | タグ(4B)
```

日付は 2020-01-01 からの日数です．日付なしカードは日数を 0 にしています（そのため 2020-01-01 当日の出席カードは作れません）．

- 鍵ストリーム：`HMAC-SHA256(key, "enc" + nonce)` の先頭5バイト
- タグ：`HMAC-SHA256(key, "tag" + nonce + 暗号文)` の先頭4バイト（改ざん検知．でたらめなコードが偶然通る確率は約43億分の1）

`nonce` が毎回ランダムなので，同じ日・同じ番号でも生成するたびに違うコードになります．
