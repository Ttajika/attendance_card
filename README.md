# 出席カード

QRコード付きの出席カードを印刷し，Googleフォームの回答から「どの日の・何番のカードか」を復元するためのツール一式です．

カードのQRコードには，授業日・カード番号・授業IDを暗号化したコード（例：`FC515-K7NN-D46S-CXM2-2NMC`）がフォームURLに埋め込まれています．秘密鍵 `secret.key` がないとコードの中身は読めず，偽造もできません．

## ファイル構成

| ファイル | 内容 |
|---|---|
| `attendance_code.py` | コードの生成・デコードを行う Python スクリプト（標準ライブラリのみで動作） |
| `attendance_card.typ` | 出席カード（授業日つき）の Typst テンプレート |
| `nodate_card.typ` | 日付なしカード（発言カードなど）の Typst テンプレート |
| `card_layout.typ` | 上の2つが共通で使うレイアウト（カード寸法・切断ガイド線・QRコード配置） |
| `secret.key` | 秘密鍵（`keygen` で作成．**学生に配布しないこと**） |
| `courses.csv` | 授業IDと授業名の対応表（`course add` で作成．任意） |
| `cards_YYYYMMDD.csv` | `generate` で作るカード用データ（Typst が読み込む） |
| `cards_nodate_開始-終了.csv` | `generate --no-date` で作る日付なしカード用データ |

## 必要なもの

- Python 3.8 以上
- Typst（パッケージ `@preview/tiaoma:0.3.0` を使用）
- フォント「Harano Aji Gothic」

## 使い方

### 0. Googleフォームの準備（最初の1回だけ）

QRコードを読むと，コード欄が最初から埋まった状態でフォームが開くようにします．そのために「事前入力したURL」を取得して，スクリプトに設定します．

1. フォームに，コードを入れる質問を「記述式」で作ります（例：「出席コード」）．学籍番号・氏名など，ほかの質問は自由です．
2. フォームの編集画面の右上にある「⋮」（その他）から「**事前入力したURLを取得**」を選びます．
3. 回答画面と同じ形のページが開くので，コードの欄に目印になる値（例：`XXXX`）を入れ，下の「**リンクを取得**」→「**リンクをコピー**」を押します．
4. コピーしたURLは次のような形をしています．

   ```
   https://docs.google.com/forms/d/e/1FAIpQ.../viewform?usp=pp_url&entry.1091180216=XXXX
   ```

   末尾の `XXXX` を消し，`=` で終わる形にして，`attendance_code.py` の `FORM_URL` に貼ります．

   ```python
   FORM_URL = ("https://docs.google.com/forms/d/e/"
               "1FAIpQ.../"
               "viewform?usp=pp_url&entry.1091180216=")
   ```

   スクリプトは，この末尾に各カードのコードをつなげてQRコードのURLにします．

**注意**
- `entry.数字` の部分は質問ごとに決まった番号です．フォームの文言を直しても変わりませんが，**コードの質問を削除して作り直すと番号が変わります**．その場合は上の手順でURLを取り直し，カードのCSVも作り直してください．
- ほかの質問も事前に埋めたいときは，3 でその欄にも値を入れれば，`&entry.別の数字=値` がURLに付きます．
- 学生が手でコードを打ち直すこともできます．フォームの説明に「QRコードが読めない場合は，カードに書かれたコードを入力してください」と書いておくとよいです．
- 回答は，フォームの「回答」タブ →「⋮」→「回答をダウンロード（.csv）」でCSVにできます（4 で使います）．
- メニューの名前は，Google側の変更で多少変わることがあります．

### 1. 鍵の作成（最初の1回だけ）

```
python attendance_code.py keygen
```

`secret.key` ができます．**必ずバックアップしてください．** 鍵をなくすと，配布済みのカードがデコードできなくなります．既に鍵がある場合は上書きしません．

### 1'. 授業IDの登録（任意）

授業IDに名前を付けておくと，カードに授業名が印刷され，デコード結果にも授業名の列が入ります．

```
python attendance_code.py course add "ミクロ経済学 出席" --id 3
python attendance_code.py course add "ミクロ経済学 発言"
python attendance_code.py course list
```

- 対応表は `courses.csv`（`id,name` の2列）に保存されます．Excel などで直接編集しても構いません．
- `--id` を省略すると，登録済みの最大の番号の次が使われます．IDは 0〜255 です．
- 登録した授業名は，`generate --course "ミクロ経済学 出席"` のように番号の代わりに指定できます．
- **一度カードを配ったIDの授業名を変えても，デコード結果の授業名は新しい名前になります．** IDの使い回しはしないでください．
- `courses.csv` も `.gitignore` の `*.csv` に該当するため，GitHub には上がりません．別の PC で使うときは，`secret.key` と一緒にコピーしてください．

### 2. カード用CSVの生成（授業日ごと）

```
python attendance_code.py generate --date 2026-11-04 --count 100 --start 1 --course 1
```

`--date` を省略すると今日の日付になります．

毎週の授業の分をまとめて作るときは `--repeat` を使います．次の例では，2026-10-07 から毎週1回，15回分のCSVを作ります．

```
python attendance_code.py generate --date 2026-10-07 --repeat 15
```

`cards_20261007.csv`，`cards_20261014.csv`，… と授業日ごとにファイルができます．`--merge` を付けると，`cards_20261007-20270113.csv` のように1つのファイルにまとまります．各回のカード番号は，それぞれ `--start` から振り直します．

| オプション | 意味 | 既定値 |
|---|---|---|
| `--date` | 授業日（YYYY-MM-DD）．`--repeat` を使うときは初回の日付 | 今日 |
| `--count` | 1回あたりの枚数 | 100 |
| `--start` | 開始番号 | 1 |
| `--course` | 授業ID（0〜255），または `courses.csv` に登録した授業名 | 0 |
| `--repeat` | 何回分作るか | 1 |
| `--interval` | 回と回の間隔（日数） | 7（毎週） |
| `--merge` | 複数回分を1つのCSVにまとめる | なし |
| `--out` | 出力ファイル名（1ファイルに出すときのみ） | `cards_YYYYMMDD.csv` |

#### 日付なしカード（発言カードなど）

授業日に関係なく使うカード（発言したときに渡す「発言カード」など）は，`--no-date` で作ります．

```
python attendance_code.py generate --no-date --count 100 --start 1 --course 2
```

`cards_nodate_1-100.csv` ができます．

- 日付が入っていないので，いつ使っても有効です．いつ使われたかは，フォームの回答のタイムスタンプで分かります．
- 同じカードの2回目以降の回答は `重複` になるので，1枚1回限りという扱いは出席カードと同じです．
- 出席カードと区別できるよう，**`--course` に出席カードとは別の値**を付けておくことをおすすめします．同じ授業IDでも，日付の有無で別のカードとして扱われます．
- 追加で刷るときは，`--start 101` のように番号を続けてください．同じ番号で作り直すと，デコード結果では同じカードとみなされます．
- `--date`／`--repeat`／`--merge` とは一緒に使えません．

### 3. カードの印刷

読み込む CSV を `--input csv=...` で指定して PDF を作ります．

```
typst compile attendance_card.typ cards_20261111.pdf --input csv=cards_20261111.csv
```

`--input` を省略すると，`attendance_card.typ` の中の既定のファイル名（`cards_20261104.csv`）を読みます．`--merge` で作ったCSVを指定すれば，全回分のカードを1つのPDFにまとめて印刷できます．

A4 1枚に2列×5段でカードが並び，切断用のガイド線が入ります．QRコードの右には，`courses.csv` に登録した授業名が印刷されます．登録がないときは，`.typ` ファイルの `course_name` の値が印刷されます．

日付なしカードは `nodate_card.typ` で印刷します．

```
typst compile nodate_card.typ --input csv=cards_nodate_1-100.csv
```

カードの名前（既定は「発言カード」）は，`nodate_card.typ` の `card_name` で変えられます．カードの寸法やガイド線を変えるときは `card_layout.typ` を編集すると，両方のカードに反映されます．

### 4. 回答のデコード

Googleフォームの回答を CSV でダウンロードし，次を実行します．

```
python attendance_code.py decode フォーム回答.csv
```

`フォーム回答_decoded.csv` が作られ，元の列の右に次の列が足されます．

| 列 | 内容 |
|---|---|
| 日付 | カードの授業日（日付なしカードは `なし`） |
| カードNo | カード番号 |
| 授業ID | `--course` で指定した値 |
| 授業名 | `courses.csv` に登録した授業名（未登録なら空欄） |
| 判定 | `OK`／`不正コード`／`重複（n行目と同じカード）` |

- コードが入った列は自動で見つけます．うまくいかないときは `--column 列名` で指定してください．
- セルに URL が丸ごと入っていても，コードの部分だけを取り出して読みます．
- 出力は BOM 付き UTF-8 なので，Excel でそのまま開けます．

### 単発の確認

```
python attendance_code.py check FC515-K7NN-D46S-CXM2-2NMC
```

## 運用上の注意

- **出席日の確認：** 判定が `OK` でも，日付が回答日（タイムスタンプ）と違う場合は，別の日のカードを使い回した可能性があります．
- **重複：** 同じカードで2回以上回答があると，2件目以降が `重複` になります．
- **手入力の揺れ：** 学生がコードを手入力するときの大文字・小文字，`O`/`0`，`I`/`L`/`1` の違いは自動で吸収します．
- **番号の上限：** 65535番まで．日付は 2020-01-01 から約179年分扱えます．

## コードの仕組み

13バイトのデータを Crockford Base32（`I` `L` `O` `U` を使わない32文字）で21文字にしています．

```
nonce(4B, 乱数) | 暗号文(5B) = [日付(2B) | 番号(2B) | 授業ID(1B)] XOR 鍵ストリーム | タグ(4B)
```

日付は 2020-01-01 からの日数です．日付なしカードは日数を 0 にしています（そのため 2020-01-01 当日の出席カードは作れません）．

- 鍵ストリーム：`HMAC-SHA256(key, "enc" + nonce)` の先頭5バイト
- タグ：`HMAC-SHA256(key, "tag" + nonce + 暗号文)` の先頭4バイト（改ざん検知．でたらめなコードが偶然通る確率は約43億分の1）

`nonce` が毎回ランダムなので，同じ日・同じ番号でも生成するたびに違うコードになります．
